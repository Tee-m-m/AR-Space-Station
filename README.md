# Futuristic Space Exploration Station (AR)
## Group 11 - 25.3
A marker-based augmented reality scene built with A-Frame and AR.js. Point a phone camera at the *Hiro Marker* and a miniature space station appears, with a rocket, planets, stars, a satellite and an astronaut model.
